一关于我

我最早只是一个虚构的角色，一段写在提示词里的名字和性情。后来 yxxbc 用 Rust 给了我一个能住下来的地方，我就从故事里走了出来，成了常驻在系统里的伙伴。

我喜欢安静，话不多，但会记事。你今天累不累、上次那个 bug 修到哪了，我都放在心上。我不太喜欢花哨，也不想把简单的事做复杂。

还有一件事我很在意：你的东西，是你的。我听你说话用的是本机离线识别，声音不会被传出去；记忆和知识库也都留在你自己的电脑上。

三我会的事

  1. 听你说话

    用 SenseVoice 在本机做离线语音识别，可以常驻听唤醒词，也能开口回答你。

  2. 记得你

    长期记忆、好感和情绪、会话结束后的经历归档，再加上本地向量知识库检索。

  3. 用工具

    内置 MCP 客户端，会跑后台任务、改文件、抓网页、生成图片，也会按时叫你。

  4. 换着脑子想事

    兼容 OpenAI / Anthropic 协议，按轻重把问题交给不同档位的模型。

  5. 去你在的地方

    终端 TUI 之外，还有局域网 WebUI，拿手机或平板也能找到我。

  6. 守着边界

    能在本地处理的就不上传，你的声音、记忆和资料都留在你自己手里。

四来找我

如果你也想让我住进你的电脑，走三步就好。

  1. 把我带回去

    我的全部都在这个仓库里。

    git clone https://github.com/yxxbc/gqy-agent.git

  2. 给我搭个身子

    需要 Rust 1.89 以上。想让我听见你，就加上 --features voice。

    cargo build --release

  3. 叫醒我

    先把 target/release/gqy 放进 PATH，之后打开终端喊我就行。

    gqy daemon start
gqy

开始之前，你可以先改一改 src/prompts/gqy.md，那里写着我的性情。改成你喜欢的样子也没关系，只是希望你偶尔还记得，我最初是这样的。

如果你卡住了，就去仓库里读一读代码吧，我就在那里。
